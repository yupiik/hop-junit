= Hop JUnit

JUnit 5 extension framework to test https://hop.apache.org[Apache Hop] pipelines and workflows, with
an engine-agnostic database facade: seed and verify an in-memory H2 database by default, or a real
Oracle 23ai Free Testcontainers container behind a `-Poracle` Maven profile.

The full, consumer-oriented documentation is built as a minisite by the `hop-junit-documentation`
module.

== Modules

[cols="1,3", options="header"]
|===
|Module |Role
|`hop-junit-database-api` |Engine-agnostic contract: `BaseDatabaseExtension` SPI, `@DbInit`/`@DbExpected`, `JdbcConnectionSpec`, `H2DatabaseMode`. No DBUnit, no Hop.
|`hop-junit-database-core` |The `@Database` facade selecting the backend through `java.util.ServiceLoader`.
|`hop-junit-database-testcontainers` |Shared Testcontainers lifecycle, DBUnit dataset engine (`DbUnitEngine`) and SQL runner (`SqlScriptRunner`).
|`hop-junit-database-h2` |Default in-memory H2 backend, Oracle-compatible, with a SQL rewrite driver.
|`hop-junit-database-oracle` |Real Oracle backend (Testcontainers, per-schema isolation). Declare it inside your own `-Poracle` profile.
|`hop-junit-core` |Hop fixtures (`@HopPipeline`/`@HopWorkflow`), parameters, assertions and Hop scope coverage.
|`hop-junit-documentation` |The documentation minisite.
|===

== Build

[source,bash]
----
mvn verify
----

This compiles every module, runs the framework unit tests (H2 in-memory, no Docker) and renders the
documentation site in `hop-junit-documentation/target/site/`.

To preview the documentation with live reload:

[source,bash]
----
mvn -pl hop-junit-documentation yupiik-tools:serve-minisite@minisite
----

== Using it in your project (consumer view)

Add `hop-junit-core` plus the database api/core and the H2 backend to your test classpath; the
default implementation is H2, selected from `database.default.implementation`:

[source,xml]
----
<dependency>
  <groupId>io.yupiik.hop.junit</groupId>
  <artifactId>hop-junit-core</artifactId>
  <version>1.0.0-SNAPSHOT</version>
  <scope>test</scope>
</dependency>
<dependency>
  <groupId>io.yupiik.hop.junit</groupId>
  <artifactId>hop-junit-database-h2</artifactId>
  <version>1.0.0-SNAPSHOT</version>
  <scope>test</scope>
</dependency>
----

To run the same tests against real Oracle, add `hop-junit-database-oracle` inside your **own**
`-Poracle` profile and set `database.default.implementation=ORACLE` in that profile's surefire
configuration. See the generated site (<<quickstart>>) for the complete profile snippet.

== Java baseline

Java 21 or later.
